# Fonts for Quran Reading

Recommended (free) fonts:

- Arabic: **Amiri Quran** (Regular)
- Malayalam: **Noto Sans Malayalam** (Regular)

Place the `.ttf` files in this folder, for example:

- `assets/fonts/AmiriQuran-Regular.ttf`
- `assets/fonts/NotoSansMalayalam-Regular.ttf`

Once they are added, we can wire them up with `expo-font` so Arabic/Malayalam text renders with the intended typography.
